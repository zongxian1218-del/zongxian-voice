# 棕仙语音 · 测试版 v2

开发中的测试版本，用于验证语音通话、屏幕共享、文件传输。
遇到问题请运行 `3-collect-diagnostics.cmd`，把生成的 `diagnostics.txt` 发回。

> **v2 修复**：v1 的启动脚本在中文 Windows 上会报一堆
> `'xxx' 不是内部或外部命令`。原因是批处理文件存成了 UTF-8，
> 而 cmd.exe 按 GBK 读取，中文注释被当成命令执行。v2 的脚本已改为纯 ASCII。

---

## 一、先决条件

- **两台 Windows 10/11 电脑**，能互相访问（同一局域网，或已用异地组网工具连通）
- **WebView2 运行时**：Windows 11 和较新的 Win10 自带。若启动失败，装一次：
  <https://developer.microsoft.com/microsoft-edge/webview2/>

**解压到桌面或文档等有写权限的位置。** 不要放 `C:\Program Files` ——
应用要往自己目录写 WebView2 缓存，那里没权限。

---

## 二、怎么跑

### 房主

1. 双击 **`1-host.cmd`**
2. 输入名字（直接回车用 `Me`）
3. **Windows 弹防火墙询问时必须点「允许访问」**，否则朋友连不上
4. 运行 `ipconfig` 查到你的 IP（形如 `192.168.1.5`），告诉朋友

### 朋友

1. 拿到整个文件夹
2. 双击 **`2-join.cmd`**
3. 输入房主的 IP，回车
4. 输入自己的名字（回车用 `Friend`）

两边都启动后，「媒体引擎」面板会显示 **`房间内 1 人，可发起通话`** —— 这是连上的标志。

---

## 三、测试顺序

### ① 文字聊天 —— 先测这个

输入框打字，按回车。对方应立刻看到。

> **这一步不通就别往下试了**，直接把结果告诉我。

### ② 语音通话

点右下角 **「发起通话」**。通话栏会显示 **延迟 / 丢包 / 抖动 / 码率 / 链路**。

**请把这五个数字告诉我**，尤其是**码率**。

**音质**用自己的话描述：发闷？金属音？断续？忽大忽小？

> 同一个房间里两台电脑外放会听到回声或啸叫，那是物理现象。
> **请戴耳机测。**

### ③ 屏幕共享

点 **「共享屏幕」** → 系统弹出选择窗口 → 选一个窗口或整个屏幕。

- 对方应能看到你的画面
- 你这边显示 `屏幕共享中 1920×1080 · 15fps`
- 点 **「停止共享」**，双方都应恢复

### ④ 文件传输

点输入框左边的**回形针图标** → 选文件（**先试几 MB 的小文件**）。

- 双方显示进度条
- 对方收到的文件在**应用目录下的 `received\` 文件夹**

> **限制**：整个文件会读进内存，**不要传超过 100 MB 的文件**。

---

## 四、出问题时

双击 **`3-collect-diagnostics.cmd`** → 生成 `diagnostics.txt` → 发回。

---

## 五、已知问题（不用报）

1. 同房间会有回声 —— 物理现象，戴耳机
2. 音质仍在调优，你的主观评价很有价值
3. 共享音频只支持「整个系统的声音」，单个应用的声音还没做
4. 不能传超过 100 MB 的文件
5. 远程控制还没做
6. 屏幕共享时**自己看不到预览**（只有对方能看到）

## 六、命令行参数（进阶）

| 参数 | 说明 |
|---|---|
| `--port <n>` | 本地服务端口。房主 45890，加入方 45891 |
| `--name <名字>` | 显示名 |
| `--room <名>` | 房间名，**双方必须一致**（脚本里是 `test`） |
| `--signal <url>` | 连到房主的信令 `ws://<房主IP>:45890/signal`。省略则自己当房主 |
| `--log-file <路径>` | 引擎日志写到文件（启动脚本已自动带上） |
