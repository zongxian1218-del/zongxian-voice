（里面有：我的地址、端口、房间、原生视频开关、单应用音频探测结论、程序目录、最近日志 ✓）

## 1. 双机联通（最基础，先做这个）

**做**：两台电脑（同一局域网 / 同一 Radmin 或 Tailscale 组网）各打开应用 →
A 点左栏「**联机 / 换房间**」或第一屏，把界面上显示的 **我的地址** 复制给 B →
B 在第一屏/联机面板里填这个地址 → 点「连接这个地址」。

**期望**：B 连上后，两边右栏成员数都变成 2，并显示**对方的真实名字**（不是"朋友A/B"）。
**要发我**：两边成员列表截图 + （失败时）复制诊断信息。

**注意**：第一次会弹 **Windows 防火墙**询问 → 要**允许**（专用+公用都勾）。

---

## 2. 语音通话（含音质三档 A/B）

**做**：① 点「发起通话」→ 对方接听，双方说话确认能听到
② 界面选**降噪：关** → 点「录音自检」→ 对着麦克风说一句话（约 3 秒，固定一句，如"今天天气不错，测试一二三四五"）
③ 档位切**标准**、再切**强力**，各录一次，**说同一句话**
④ 录音存在 exe 同级 `recordings\`，**文件名带档位**

**期望**：通话双方都能听清；三次录音文件名档位正确、都录满 3 秒。
**要发我**：`recordings\` 里三个文件名（或把整个目录打包发我）—— 我用工具出对比数字（RMS/噪声底/语音带占比/谱质心）。

---

## 3. 屏幕共享（这是主功能，重点测）

**做**：① A 点「共享屏幕」→ 系统弹窗里选一个窗口
② B 点「观看」→ 看画面
③ A **停止共享** → 再**重新共享一次**
④ **C 加入**（A 已经在共享之后才进来）→ 也点观看
⑤ 共享时**拖着 A 的窗口移动 / 最小化 / 还原**

**期望**：B、C 都能看到画面；后加入的 C 也能看到；A 移动窗口时画面区域跟着走、不错位、不黑屏。
**要发我**：三方的成员列表 + 双方画面截图（尤其 C 的画面）+ 失败时的诊断信息。

---

## 4. 单应用音频（本机到底支不支持）

**做**：点 **齿轮 → 「检测「单个应用音频」」**（或点一次共享，它也会在后台自己探一次）

**期望**：日志区出现 `【音频能力】…` 结论；**应用不会因此崩溃或卡住**。
**要发我**：那几行结论 + 应用有没有异常。

**说明**：即使显示"可用"，现在也**还不能真的把单个应用的声音送进通话**（那段 PCM 通路还没做，是明确的遗留项）。

## 5. 界面/稳定性（顺手看一眼）

- 第一屏：能不能起名字、扫描到对方房间、点「进入」进主界面
- 左栏是否显示"扫描到 N 个房间"（不该再有三张假卡片）
- 拖窗口/最小化/还原：布局不散
- 挂机 10 分钟：日志不刷屏、内存不一直涨
- 关掉对方应用：这边成员数应减少、共享应提示"对方停止共享"

## 6. A 线（文件传输）安装包 —— 这项只能真机验

**做**：双击 `棕仙的传输软件-安装包-1.0.exe` → 装 → 检查**桌面图标 / 开始菜单 / 控制面板卸载项** → 传个文件 → 用开始菜单的"卸载"卸掉。

**期望**：三处都有；能传文件；卸载干净。
**要发我**：哪一处缺（我这边在沙箱里验不了这三项，只能靠你的真机结果）。

## 测完我们要讨论的"目标"

我会带着这些一起聊（你也可以先想）：
1. 现在**卡在哪**：哪些是环境限制（我这边验不了）、哪些是真 bug
2. 你**最想要**的是什么：稳定双人语音通话？屏幕共享给朋友看？3 人一起看同一路？
3. 目标的**验收标准**：怎么算"能用"（例如：两台真机、连续 30 分钟通话不掉、共享延迟 <200ms）
4. 是否砍掉一些方向（例如单人测试不方便的功能、TOPMOST 这类边缘问题）
